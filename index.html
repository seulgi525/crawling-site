📋 사용 방법
1
로그인 정보 입력

인스타그램 ID와 PW를 입력합니다.
입력하지 않으면 진행되지 않습니다.

2
검색어 입력

아래 3가지 방식으로 입력할 수 있습니다.

강남맛집 일반 키워드 검색
#강남맛집 해시태그 검색
@nike 특정 계정 바로 수집
@nike, @adidas 여러 계정 동시 수집
3
결과 선택 (키워드/해시태그인 경우)

검색 결과 상위 5개가 표시됩니다.
원하는 번호를 선택하거나 more를 입력해 더 많은 결과를 확인할 수 있습니다.

4
수집 건수 설정

계정당 수집할 게시물 수를 입력합니다.
입력하지 않으면 기본값 10건으로 진행됩니다.

5
저장 경로 설정

파일이 저장될 경로를 입력합니다.
입력하지 않으면 기본경로 c:\py_temp\에 저장됩니다.
