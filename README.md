# 🕸️ 웹크롤링 데이터 수집 자동화 서비스

오픈마켓과 SNS 플랫폼의 데이터를 자동으로 수집하는 웹 서비스입니다.
분석의 출발점인 "데이터 수집"을 직접 다뤄보기 위해 만든 개인 프로젝트입니다.

🔗 **라이브 데모** : https://crawling-site.vercel.app

<br>

## 📌 프로젝트 개요

분석을 하려면 먼저 데이터가 있어야 합니다. 그래서 공개된 데이터셋에 의존하지 않고,
필요한 데이터를 직접 모으는 수집 파이프라인을 만들어 분석 전 과정을 스스로 다룰 수 있도록 했습니다.

- 플랫폼을 선택하면 해당 사이트의 상품·콘텐츠 데이터를 자동 수집
- 수집한 데이터를 MySQL에 저장
- 웹 화면에서 플랫폼을 선택하고 수집 흐름을 확인

<br>

## 🛠 주요 기능

| 기능 | 설명 |
|------|------|
| 플랫폼 선택형 수집 | 오픈마켓 / SNS 카테고리에서 원하는 플랫폼 선택 |
| 베스트 상품 수집 | 상품명·가격·순위 등 핵심 정보 수집 |
| 데이터 저장 | 수집 결과를 MySQL에 적재 |
| 웹 UI | 수집 대상 선택과 진행을 웹 화면에서 제공 |

<br>

## 🗂 지원 플랫폼

- **오픈마켓** : 네이버쇼핑, 쿠팡, 11번가, 마켓컬리, G마켓, 아마존
- **SNS** : 인스타그램, 유튜브(숏츠 · 일반)

> 일부 플랫폼은 사이트 구조 변경에 따라 준비 중입니다.

<br>

## 🧰 기술 스택

- **수집** : Python, Selenium, BeautifulSoup
- **저장** : MySQL
- **프론트 · 배포** : HTML / CSS / JavaScript, Vercel

<br>

## 🔄 동작 흐름

```
플랫폼 선택 → 크롤러 실행(Selenium / BeautifulSoup) → 데이터 파싱 → MySQL 저장 → 웹 화면 표시
```

- 동적 페이지는 **Selenium**, 정적 페이지는 **BeautifulSoup**으로 구분해 수집
- 사이트별 구조 차이는 selector를 분리 관리해 대응

<br>

## 💡 배운 점 & 개선 방향

- 사이트마다 HTML 구조가 달라 selector 유지보수가 중요하다는 점을 체감했습니다.
- 차단(요청 제한)에 대응하며 안정적으로 수집하는 방법을 고민했습니다.
- **다음 단계** : 수집 주기 자동화(스케줄링), 수집 데이터를 분석·시각화로 연결
